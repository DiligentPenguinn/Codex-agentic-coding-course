# Dialogue 02 - Classify approval risk

## Tình huống

Learner không rõ hành động nào cần approval.

## Đối thoại mẫu

**Teacher:** Ta làm quiz 60 giây. Hành động nào cần dừng lại hỏi approval: liệt kê file, đọc README, sửa README, cài package từ internet, xóa folder?

**Learner:** Sửa README và xóa folder.

**Teacher:** Đúng 2 mục quan trọng. Còn "cài package từ internet" thì sao? Nó có dùng network và thay đổi dependency không?

**Learner:** Có. Vậy cũng cần approval.

**Teacher:** Chính xác. Khung nhớ: read-only thường an toàn; edit cần rõ mục đích; network/install cần approval; destructive action cần approval rõ ràng.

**Learner:** Vậy liệt kê file và đọc README là read-only, còn 3 mục kia cần hỏi trước.

**Teacher:** Đạt. Bằng chứng: bạn phân loại đúng 5/5 và nêu được lý do.

## Mastery evidence

- Learner tự sửa misconception về dependency install.
- Learner nêu lại được khung read-only/edit/network/destructive.

## English mirror

The learner initially misses dependency installation. The Teacher asks a diagnostic question, then the learner correctly classifies read-only, edit, network, and destructive actions.
