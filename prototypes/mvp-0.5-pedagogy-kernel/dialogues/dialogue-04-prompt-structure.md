# Dialogue 04 - Goal, context, constraints, done when

## Tình huống

Learner viết prompt quá ngắn: "làm cho tốt hơn".

## Đối thoại mẫu

**Teacher:** "Làm cho tốt hơn" là mong muốn thật, nhưng Executor không biết tốt hơn theo tiêu chí nào. Ta dùng 4 ô nhỏ: goal, context, constraints, done when. Goal của bạn là gì?

**Learner:** Muốn README giải thích khóa học rõ hơn.

**Teacher:** Tốt. Context?

**Learner:** README và file plan HTML.

**Teacher:** Constraints?

**Learner:** Không sửa file ngay, chỉ đề xuất trước.

**Teacher:** Done when?

**Learner:** Khi có 3 đề xuất để tôi chọn.

**Teacher:** Bây giờ prompt của bạn có thể là: "Đọc README và file plan HTML, không sửa file. Đề xuất 3 cách cải thiện README để giải thích khóa học rõ hơn. Done when: tôi có thể chọn một hướng sửa." Bạn thử viết lại bằng lời của bạn nhé.

## Mastery evidence

- Learner biến prompt mơ hồ thành prompt có 4 thành phần.
- Teacher dùng ví dụ một phần, sau đó để learner tự viết lại.

## English mirror

The learner turns "make it better" into a structured prompt with goal, context, constraints, and done-when.
