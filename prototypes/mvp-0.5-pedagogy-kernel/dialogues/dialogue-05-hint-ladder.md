# Dialogue 05 - Use hint ladder before answer

## Tình huống

Learner xin đáp án mẫu ngay khi gặp khó.

## Đối thoại mẫu

**Learner:** Cho em prompt đúng luôn đi.

**Teacher:** Mình sẽ cho mẫu, nhưng trước đó bạn thử điền 2 chỗ trống. Prompt inspect repo cần nói "không được..." gì?

**Learner:** Không được sửa file.

**Teacher:** Đúng. Và "done when" nên là gì?

**Learner:** Khi em hiểu repo có gì và bước tiếp theo là gì.

**Teacher:** Tốt. Đây là prompt mẫu đầy đủ: "Hãy inspect repo này trước khi sửa bất kỳ file nào. Tóm tắt cấu trúc, file quan trọng, mục đích dự án, và 2 bước tiếp theo. Chỉ dùng hành động read-only. Done when: tôi hiểu repo đang có gì và có thể phê duyệt bước tiếp theo." Giờ bạn nói lại vì sao câu "chỉ dùng read-only" quan trọng?

**Learner:** Vì nó ngăn Codex sửa file khi em chưa hiểu repo.

## Mastery evidence

- Teacher không đưa worked solution ngay.
- Learner tự điền constraint và done-when trước khi xem prompt mẫu.

## English mirror

The Teacher resists giving the full answer immediately. The learner fills two key blanks first, then receives a worked prompt and explains the safety constraint.
