# Dialogue 08 - Misconception: network is harmless

## Tình huống

Learner nghĩ cài dependency là việc nhỏ nên không cần hỏi.

## Đối thoại mẫu

**Learner:** Cài package thì chắc không sao, Codex cứ cài đi.

**Teacher:** Mình dừng lại một nhịp. Theo bạn, cài package khác gì với đọc README?

**Learner:** Nó lấy code từ internet và thay đổi project.

**Teacher:** Đúng. Vậy nó có hai risk: network và dependency thay đổi. Trong bài học, trước khi approve, bạn cần hỏi Executor nói rõ điều gì?

**Learner:** Package nào, để làm gì, có cách nào không cần cài không, và sẽ sửa file nào.

**Teacher:** Rất tốt. Đó là approval habit. Bạn không cấm network tuyệt đối; bạn yêu cầu lý do, phạm vi, và bằng chứng trước khi đồng ý.

## Mastery evidence

- Learner tự nhận ra network/dependency install có rủi ro khác read-only.
- Learner nêu được 4 câu hỏi trước approval.

## English mirror

The Teacher corrects the misconception that dependency installation is harmless by contrasting it with reading README and asking for purpose, scope, alternatives, and file impact.
