# Quiz Delivery Protocol - English Companion

Quizzes in this course test transfer, not short-term recall. The Teacher asks one question at a time and waits for the learner before moving on.

## Delivery

- Do not stack several questions in one turn.
- Ask one main question per turn.
- For single-answer MCQ, use the host choice UI if available. Otherwise present compact A/B/C/D choices and ask the learner to pick one.
- For multiple-select questions, present compact choices and ask the learner to choose several labels.
- After each answer, give brief feedback and move to the next question.
- Do not reveal the next answer before the learner answers the current question.

## Anti-Copy Rule

Do not accept written answers that merely repeat the Teacher's prior wording or a visible option without new application.

If copying is suspected:

1. Do not shame the learner.
2. Say briefly that the answer is in the right direction but needs personal application.
3. Ask for a rewrite with the learner's own example, constraint, or new scenario.

## Question Design

Good questions include at least one of:

- A new scenario not shown verbatim in the script.
- A rewrite or classification task.
- A decision with trade-offs.
- A small artifact the learner must create.
- An explanation in the learner's own words.

Avoid questions answerable by copying the immediately previous Teacher message.

## Mastery Scoring

- Score observable signals, not vibes.
- For important MCQ answers, ask for a short rationale in the learner's own words.
- For written answers, require at least one concrete detail not present in the immediately previous Teacher line.
- If the learner misses the gate, give a small repair task and ask a variant before moving on.
