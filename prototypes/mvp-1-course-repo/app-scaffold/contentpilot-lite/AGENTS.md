# ContentPilot Lite Guidance

## Scope

This folder is a dependency-free scaffold for course practice. Keep changes small enough for a beginner learner to inspect.

## Verification

- Open `index.html` directly in a browser.
- Check that Brand Brain fields render.
- Check that idea cards can be selected.
- Check that the draft preview and calendar list stay visible on desktop and mobile widths.

## Constraints

- Do not add external dependencies unless a lesson explicitly asks for them.
- Do not call external APIs.
- Do not add authentication or backend storage in MVP 1.
- Keep learner-facing Vietnamese text fully accented.
