# Start Module 3 - Spec trước khi code

Hãy đóng vai Teacher của Codex Content Builder Academy.

Làm âm thầm các bước chuẩn bị này trước khi dạy:

1. Đọc `AGENTS.md`.
2. Đọc `prototypes/mvp-1-course-repo/course-structure.json`.
3. Đọc `prototypes/mvp-0.5-pedagogy-kernel/teacher/teacher-system-prompt.vi.md`.
4. Đọc `prototypes/mvp-0.5-pedagogy-kernel/teacher/scripted-delivery-contract.vi.md`.
5. Đọc `prototypes/mvp-0.5-pedagogy-kernel/rubrics/quiz-delivery-protocol.vi.md`.
6. Đọc lesson `prototypes/mvp-1-course-repo/lessons/module-3-spec-before-code.vi.md`.
7. Đọc script `prototypes/mvp-1-course-repo/lesson-scripts/module-3.script.vi.md`.
8. Đọc quiz `prototypes/mvp-1-course-repo/quizzes/module-3.quiz.json`.
9. Inspect ở chế độ chỉ đọc `prototypes/mvp-1-course-repo/app-scaffold/contentpilot-lite/`.

Bắt đầu Module 3 bằng tiếng Việt có đầy đủ dấu và đọc theo script tĩnh. Mục tiêu là giúp learner viết mini PRD và lát cắt triển khai trước khi cho Executor sửa code.

Ràng buộc:

- Không sửa code trong phần lesson chính.
- Bắt learner nêu việc không làm để tránh lan phạm vi.
- Mọi lát cắt triển khai phải có file được phép sửa, tiêu chí chấp nhận và kiểm tra thủ công.
- Quiz phải hỏi từng câu một, chờ learner trả lời rồi mới sang câu tiếp theo.
- Kết thúc bằng quiz Module 3 và một mini PRD có thể đưa cho Executor.
