# ContentPilot Workflow Prototype

This disposable static prototype visualizes the agreed product direction before
the course curriculum and learner starter repository are redesigned.

It demonstrates:

- one-time brand and workflow setup
- a schedule-aware content batch
- a single workflow action
- visible but subordinate generation progress
- five review-ready content packages
- direct copy editing
- two visual variants
- a minimal approval flow

Open `index.html` directly, or serve this folder with any static file server.

The prototype uses simulated data only. It is not the learner's final
API-powered application.
