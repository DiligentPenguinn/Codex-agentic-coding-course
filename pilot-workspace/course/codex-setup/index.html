Chọn theo tác vụ

Model là hệ thống AI xử lý yêu cầu

Giữ thiết lập mặc định nếu bạn chưa chắc. Chỉ đổi model hoặc mức suy luận khi công việc thật cho thấy bạn cần nhanh hơn hoặc cần phân tích sâu hơn. Mức suy luận là lượng công sức model dành cho việc phân tích trước khi trả lời.

Terra
