# Codex Content Creator Course

This repo contains the working materials for **Codex Content Builder Academy**, a Vietnamese-first course that teaches marketers and creators to use Codex by building practical AI content tools.

## Current authority

- [Pilot 0.1 workspace](pilot-workspace/START_HERE.md) is the only runnable
  course. It contains the intro, Module 1, project-local Teacher/start skills,
  local resume state, learner artifacts, and a clean copy of the real
  ContentPilot starter.
- [ContentPilot learner starter](starters/contentpilot/README.md) is the current
  validated Next.js baseline. It has honest empty states and generic local
  infrastructure; learners build the product-specific workflows.
- [Planning handoff](docs/planning/content-automation-course-handoff.md) and its
  linked contracts define the approved prologue + six-module public-course
  direction.
- [UI, UX, and interaction review](docs/planning/ui-ux-interaction-review-index.md)
  maps the current experience, planned behavior, prototypes, and remaining
  documentation gaps.
- [Course Experience Companion visual prototype](prototypes/mvp-3-course-experience-companion/README.md)
  is the single current UI reference for the future learner-facing teaching
  application. It remains fixture-driven and disconnected from a real Teacher
  or Codex runtime.

From the repository root, `$start-course-lesson` and `$course-teacher` delegate
to the skills inside `pilot-workspace/`. Pilot 0.1 currently supports `intro`,
`module-1`, and `resume`.
